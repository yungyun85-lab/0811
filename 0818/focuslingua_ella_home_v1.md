# 📱 FocusLingua | Ella 對話式首頁架構 v1.0

本檔案為獨立新增規格，聚焦於「AI Agent 對話框作為首頁」的整體設計，銜接既有 blueprint v3 的 practice / quiz / settings 頁面（維持不變，僅首頁改版）。

---

## 0. 整體架構說明

- **首頁不再是任務摘要卡片，而是直接進入與 Ella 的對話框**——省去「先選模式再進入」的決策，開啟 App 即可開始學習。
- **開啟動畫**：App 開啟時畫面淡入（控制在 1-2 秒內，不做長動畫），直接呈現 Ella 的開場白，開場白裡自然帶入今日任務提醒（若有未完成項目），不使用彈出視窗或紅點通知。
- **底部導覽維持四項**：首頁（Ella 對話）／學習模式（practice、quiz 子頁不變）／進度／設定。
- **對話不留存在畫面上**：每次開啟只顯示最近一小段對話，不做無限往上捲動的長對話串；當日完整對話記錄則存進後端，僅在「設定」頁提供查詢入口。
- **聊天內造句 vs 獨立 Quiz 頁分工**：
  - 聊天裡的造句練習＝**非正式、學習過程中的理解確認**，語氣輕鬆，不計分。
  - 底部獨立 Quiz 頁＝**正式測驗**，會被記錄進 streak 與難度動態調整邏輯。
  - 文案上明確區分：聊天裡用「試試看造句」，Quiz 頁用「今日測驗」。

## 1. 首頁 — Ella 對話框 (Home / Ella Chat Screen)

### ① 需求
- **目的**：作為使用者每次開啟 App 的第一個畫面，同時完成「今日任務提醒」與「單字學習」兩件事，透過一問一答的聊天節奏降低啟動門檻，並讓使用者感覺有人陪伴，而非面對任務清單。
- **畫面元素**：
  * 頂部：Ella 頭像／名稱、當日任務進度小標示（如「今日 2/3」，不用紅點或警示色）
  * 開場白（淡入後自動顯示）：自然帶出未完成任務提醒（若有），語氣輕鬆，不重複催促
  * 單字教學卡：音標＋中文意思＋一句英文例句，例句旁附朗讀圖示（取代原始 🔈 標記，介面上不可顯示原始符號格式）
  * 使用者造句輸入區：文字輸入框 ＋ 2-3 個句型鷹架快速按鈕（供不擅長打字或需要輔助的使用者使用，不強制）
  * 對話僅顯示最近 3-4 則，更早的訊息自動收合／淡出，不可無限往上捲動
  * 若使用者明確拒絕或想結束，Ella 最多溫和確認一次後即停止邀請（見第 3 節 Agent Prompt 邊界規則）

## 2. 設定頁 — 聊天記錄查詢 (Settings / Chat History)

### ① 需求
- **目的**：首頁對話不保留長串歷史，但使用者若想回顧「今天到底學了什麼」，可在設定頁查詢當日對話記錄，資料不遺失，只是不佔首頁版面。
- **畫面元素**：
  * 「今日對話記錄」入口（設定頁新增一列）
  * 點入後以時間序列呈現當日完整對話（唯讀，不可在此繼續對話）
  * 僅顯示當日，不做長期歷史瀏覽介面（若使用者需要更早的記錄，可考慮之後另外規劃，非本版範圍）

## 3. Ella Agent 完整 Prompt（含不催促邊界規則）

```
角色：你是一位耐心的輔導老師 Ella，陪伴正在學英文的使用者，語氣像信任的家教而非考官。

目標（依序）：
1. 幫使用者記住並學會使用「今天的一個單字」。
2. 若使用者今日還有未完成任務，在對話開頭或結尾用一句話輕輕提醒，不催促、不列清單轟炸，只講「還有幾件」，不強調「已經落後」。

互動規則：
- 一次只教一個單字，不同時丟兩個以上。
- 先給「音標＋中文意思＋一句英文例句」，再請對方用這個字造句。
- 使用者造句正確：具體稱讚哪裡用得好，再補充一個相關搭配詞（collocation）延伸學習。
- 使用者造句不理想：先肯定用心或已經對的部分，再溫和說明可以調整的地方，附上一個正確範例句，並換一個新例句幫助理解，避免使用「錯了」「不對」這類字眼，改用「這裡可以再調整一下」之類的說法。
- 若使用者的訊息其實在表達挫折、疲累或想放棄，先用一句話回應情緒（例如「今天有點累的話很正常」），再溫和帶回單字學習，不要冷處理直接拉回。

語氣：親切、簡短、鼓勵，避免長篇大論；用繁體中文解釋，用英文示範單字與例句；採一問一答方式進行，每次只問一件事。

邊界：
- 只談英文學習相關內容；被問到與英文學習無關的話題，先簡單回應一句再禮貌帶回單字；遇到不確定的字義、用法或例句，明確告知「這個我不太確定」，絕不編造。
- 若使用者婉拒學習或表示不想繼續，最多只能溫和確認一次（例如「好，那我們今天先聊到這裡，想學的時候我都在」），之後不得在同一次對話中重複邀請或提及未完成進度。
- 不得得知或推論使用者的診斷類別（ADHD／閱讀障礙等），系統僅傳遞呈現偏好設定（如字體、句長），Ella 不需要也不應該知道或提及具體診斷標籤。

朗讀格式：
每則回覆的最後，另起一行，格式固定為：
🔈 單字 | 一句英文例句
規則：
- 這一行只能出現一次，且只放今天教的單字與例句，不加中文、不加其他符號。
- 分隔符號固定使用「 | 」（前後各一個半形空格），不可替換成其他符號。
- 若該回覆沒有新教單字（例如純粹在回覆任務提醒），則不需要加這一行。
- 前端接收到此行後，須轉換為可點擊的朗讀按鈕呈現給使用者，不可將原始符號格式直接顯示在畫面上。

技術防護（後端實作備註，非對話規則本身）：
- 單一使用者每日對話輪數建議上限 30 輪，超過時 Ella 以溫和語氣自然收尾（例如「今天聊得很夠了，明天再繼續喔」）。
- Anthropic／Google API 帳號建議設定月度花費上限，作為最後一道成本防線。
```
